# BentoFit — Bento Grid Workout Tracker (iPhone PWA)

Веб-приложение для тренировок на iPhone: готовые программы под цель, 79 упражнений с анимированной техникой, таймер и дневник. Работает офлайн, данные хранятся на устройстве.

## Что где лежит

- `js/exercises-data.js`: упражнения, описание техники, инвентарь, цели и ссылка на исследование.
- `js/figures.js`: SVG-фигурки. Каждое упражнение описано двумя позами, начальной и конечной. Анимация строится из них.
- `js/programs-data.js`: дни-шаблоны, программы по целям и список источников.
- `css/app.css`: весь дизайн. Цвета взяты с соревновательных блинов: 25 красный, 20 синий, 15 жёлтый, 10 зелёный, 5 белый.

После любой правки файлов увеличьте номер `CACHE_NAME` в `sw.js`, иначе телефон продолжит показывать старую версию.

## Инструкция по деплою на GitHub Pages:

1. Создайте новый репозиторий на GitHub (например, `bentofit` или `<username>.github.io`).
2. Распакуйте содержимое архива в корень репозитория:
   - `index.html` должен находиться в корне репозитория.
   - Папки `css/`, `js/`, `icons/`, файлы `manifest.json` и `sw.js` также должны быть в корне.
3. Закоммитьте и отправьте файлы в ветку `main`:
   ```bash
   git add .
   git commit -m "Initial commit of BentoFit PWA"
   git push origin main
   ```
4. Откройте репозиторий на GitHub:
   - Перейдите в **Settings** (Настройки репозитория) -> **Pages**.
   - В разделе **Build and deployment**:
     - Source: **Deploy from a branch**
     - Branch: выберите `main` и папку `/ (root)`
     - Нажмите **Save**.
5. Через 1-2 минуты сайт станет доступен по адресу:
   `https://<username>.github.io/<repository-name>/`

## Статус-бар на iPhone

В `index.html` стоит `apple-mobile-web-app-status-bar-style` со значением `default`. Значение `black-translucent` на iOS 26 укорачивает приложение снизу и размывает его верх. iOS читает эту настройку только при добавлении значка, поэтому после её смены значок нужно удалить и добавить заново.

## Установка на экран «Домой» (iPhone):
1. Откройте полученную ссылку в браузере Safari на iPhone.
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх внизу экрана Safari).
3. Прокрутите меню и выберите **«На экран "Домой"»** (*Add to Home Screen*).
4. Нажмите **«Добавить»**.
5. Приложение готово к использованию в полноэкранном режиме и будет работать полностью автономно (offline).
